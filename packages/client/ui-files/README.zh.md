# @deepseek-ai/dsh-client-ui-files

[English](README.md) | 中文

工作区文件插件。`FilesPanel` 注册进侧边栏的 `sidebar.files` 区域插槽，渲染所选工作区文件夹的常驻文件树；侧边栏的「会话/文件」视图切换会把它替代会话列表显示出来。

文件树通过 `host.listFiles` 原语（由 workspaces 服务暴露）逐级懒加载。它以所选工作区为根——即当前会话的工作目录、工作区据以命名的文件夹——通过全局 `useSessions` 标准套件读取，并在当前会话变化时重新生根；无当前会话时回退到宿主进程工作目录。展开某个目录时按需扫描。条目先目录后文件，各组按名称排序；宿主标记的隐藏条目（POSIX 上以点开头）不显示。被宿主完整结果上限截断的层级会显示截断提示。加载、空目录与失败状态在其所属层级内联显示。右键点击条目会弹出上下文菜单，通过 `host.openPath` 在系统文件管理器中显示条目：文件行打开其所在文件夹，目录行打开该目录本身。

视图切换选「文件」时，面板填满侧边栏浏览区域；收起的窄栏仍显示会话列表，因此面板是仅宽屏的视图。它是普通的页内内容，不会创建或指向原生窗口。

面板的文案以 `files` 命名空间在此注册语言包。目标插槽由 ui-sidebar 声明，因此 `apply` 使用 `slots.inject()` 在声明生命周期内注册，并在插槽恢复后重新注册。

## Model Experience

无。文件浏览器属于浏览器界面，任何内容都不会进入模型请求。

#### KV Cache effect

无；本包既不组装也不发送提供方请求。

## Known Limitations and Deferred Work

- **无变更操作**——文件树仅列出并在系统中显示条目，不提供重命名、删除或新建操作。
- **无自由路径输入**——根目录跟随当前会话的工作区（回退到宿主 cwd），没有路径输入或任意切换根目录的控制。
- **隐藏条目始终隐藏**——没有开关可以显示宿主标记的隐藏（点开头）条目。
